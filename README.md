# Сеть насквозь

An interactive textbook of the whole web industry, from the first web page to the
agentic web: how the web works, HTML, CSS, design and design systems, JavaScript,
servers, databases, CMS and Jamstack, infrastructure, writing, copywriting and
marketing frameworks, storytelling, SEO and GEO, metrics, quality and law, AI site
builders, and what comes next. Every lesson has theory, a live demonstration, a
test and practice, done inside the app on one site, rebuilt in each era of the web.

No registration: progress stays in your browser.

**Status:** in development. The design is in [`docs/specs/2026-10-27-learn-design.md`](docs/specs/2026-10-27-learn-design.md).
